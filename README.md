# Lista de Tarefas

Aplicação simples para gerir tarefas, feita em HTML, CSS e JavaScript puro.

## Funcionalidades

- Adicionar tarefas (com o botão ou a tecla Enter)
- Marcar tarefas como concluídas (riscadas) ao clicar nelas
- Apagar tarefas
- As tarefas ficam guardadas no browser com `localStorage`

## Tecnologias

- HTML5
- CSS3
- JavaScript (DOM, eventos, localStorage)

## Como usar

1. Faz o download ou clona o repositório:
   `git clone https://github.com/ninofernando/lista-de-tarefas.git`
2. Abre o ficheiro `index.html` no browser.

## O que aprendi

- Manipular o DOM e criar elementos com JavaScript
- Trabalhar com eventos (click, keydown)
- Guardar e ler dados com `localStorage` e `JSON`
